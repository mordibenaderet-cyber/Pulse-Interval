Pulse Interval — v3.0
Designed & Developed by Mordi Ben Aderet

התקנה:
1. חלץ את כל קובצי ה-ZIP לתיקייה אחת.
2. העלה את כל תוכן התיקייה ל-Netlify Drop, או לפרויקט GitHub Pages.
3. פתח את כתובת האתר ב-Safari באייפון.
4. לחץ על שיתוף -> הוסף למסך הבית.

אפשר להשתמש ללא שרת, ללא חשבון וללא שירות בתשלום.
ניתן להוסיף ולערוך תוכניות עם זמני עבודה, מנוחה וסטים לכל תרגיל ומספר סבבים לאימון.
התוכניות נשמרות ב-localStorage במכשיר, תחת אותו מקור (domain).
לכן חשוב לפרסם על אותה כתובת אתר שבה השתמשת בגרסה הקודמת,
ולייצא מדי פעם גיבוי מתוך הגדרות.

תיקוני שעון v3:
- המעברים בין שלבים משתמשים במועד סיום מוחלט לפי Date.now.
- עיכובי דפדפן אינם מקצרים או מאיצים שלבים.
- זמן מנוחה אחרי כל סט כולל הסט האחרון, והוא נכלל גם במשך המוצג.
- היסטוריית אימונים לאחר השלמה; ייצוא וייבוא JSON.
- כפתורי השהיה/המשך/שלב הבא/שלב קודם.
- Wake Lock במכשירים תומכים, ללא הבטחה שיפעל בכל גרסאות iOS.

חשוב: iOS עלולה לעצור צלילים או JavaScript בעת נעילת המסך. הספירה תדביק
פערים לפי זמן אמת כשחוזרים לאפליקציה, אך צלילים ברקע אינם מובטחים.

הקבצים עצמאיים. אין תלויות חיצוניות או צורך ברישום.
