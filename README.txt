Pulse Interval - אפליקציית טיימר אימונים

העלאה ל-Netlify:
1. חלץ את קובץ ה-ZIP.
2. העלה את התיקייה או את תוכנה אל Netlify Drop.
3. פתח את כתובת האתר ב-Safari באייפון.
4. שיתוף > הוסף למסך הבית.

יכולות: תוכניות ללא הגבלה (בכפוף לנפח אחסון הדפדפן), זמנים וסטים שונים לכל תרגיל, סבבים, מנוחות, עריכה/שכפול/מחיקה, טיימר, התראות צליל, גיבוי וייבוא JSON, תמיכה אופליין לאחר התקנה.

מגבלות: אין סנכרון בין מכשירים; נתונים מקומיים בלבד. iOS עלול להשהות את הטיימר/הצלילים ברקע. יש להשאיר מסך פעיל. זמן הטיימר מבוסס על שעון מונוטוני ומתעדכן כשחוזרים לאפליקציה כל עוד הדף נשאר פתוח.
